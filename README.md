## cinematic-reels-studio
Multi-agent workflow for cinematic Reels/Shorts with ffmpeg and Remotion.

### Install (Claude Code)
```bash
git clone https://github.com/Radiiduration/claude-skills.git ~/code/claude-skills
ln -s ~/code/claude-skills/cinematic-reels-studio ~/.claude/skills/cinematic-reels-studio
```

### Install (claude.ai)
Download `cinematic-reels-studio.zip` from the latest Release, then upload it in Settings, Capabilities, Skills.
